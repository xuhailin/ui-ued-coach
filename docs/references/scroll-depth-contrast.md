# 滚动落差经验卡

## 场景

- 参考对象：[CURA Climate](https://www.curaclimate.com/)
- 适用于气候科技、工业科技、品牌官网、作品集、专题页这类需要“边滚边讲故事”的页面。
- 容易误读成“用了视差所以高级”，但真正有效的是：滚动输入和视觉反馈之间有意制造节奏差。

## 关键判断

滚动落差不是让元素随便快慢不同，而是让用户感到：

- 我滚了一小段，画面却停住讲完一句重点。
- 我滚过一个边界，材质、颜色、情绪突然换了一个世界。
- 我以为是普通下滑，结果进入了一个更大的画布或叙事机器。

记住这个判断：滚动落差的本质是“滚轮距离”和“视觉事件”的不等价。

## 原理

普通页面是线性的：滚多少，内容就上移多少。

有落差的页面会把滚动拆成几种不同结果：

- **位移被消耗**：`sticky` 区块让用户继续滚，但主画面暂时固定。
- **层级速度不同**：前景图、背景图、文字、网格线以不同速度或不同方向移动。
- **视觉语义突变**：浅色到暗色、实验室到工业、抽象数据到真实材料。
- **尺度突然变化**：从可读正文切到超大字、全屏图、被裁切的巨大背景字。
- **交互节奏变换**：沉浸叙事之后回到常规卡片、列表和 CTA。

落差成立的前提是叙事顺序清楚。否则用户只会觉得页面晃、慢、乱。

## CURA 的结构公式

CURA 的首页可以拆成这条滚动节奏：

```text
100vh Hero
→ 约 160vh Sticky Statement
→ 约 250vh Sticky Visual Loop
→ 暗色 Full-bleed 工业叙事段
→ 酒红 Feature / Swiper 产品说明
→ Partners / Blogs 常规信息收口
```

关键不是每段都动，而是前面用落差抓住注意力，后面把节奏放平，让用户重新读信息。

## 可复用做法

### 1. 首屏先建立重心

首屏最好有明确的上下或左右重心：

- 上半：品牌命题、大标题、白底或低噪声背景。
- 下半：强材质图、色块、产品物件、自然/工业纹理。

这样第一次滚动时，用户会感觉一个重心离场，另一个世界进场。

### 2. 用 sticky 消耗滚动距离

适合在一句核心观点或一组数据上使用：

```css
.story-section {
  min-height: 160vh;
}

.story-sticky {
  position: sticky;
  top: 0;
  height: 100vh;
}
```

经验值：

- `120vh-160vh`：适合一句话或两个状态切换。
- `180vh-250vh`：适合多图层、步骤循环、横向推进。
- 超过 `300vh` 要谨慎，除非内容密度足够，否则会拖。

### 3. 让一次滚动跨过“材质边界”

不要只换背景色。更强的落差来自材质和语义一起变：

- 白底大字 -> 岩石、泥土、金属、烟尘。
- 实验室图 -> 工厂、矿山、城市基础设施。
- 抽象图形 -> 真实产品、真实场景、真实数据。

用户会把这种切换理解成叙事推进，而不是装饰转场。

### 4. 保留一个稳定锚点

滚动落差强的时候，页面需要一个锚点防止迷路：

- 固定网格线。
- 持续出现的边距系统。
- 位置稳定的标签、页码、进度条。
- 相同风格的 CTA 或 section label。

CURA 的竖向网格线和胶囊标签就是这种锚点。

### 5. 后半段收回普通信息流

沉浸式滚动不能一路到底。进入信任背书、合作方、新闻、报价、联系时，应该降低落差：

- 少用 sticky。
- 少用大幅视差。
- 回到卡片、列表、分栏。
- 保证阅读和点击效率。

这会让前面的情绪价值转化成后面的信息理解。

## 反模式

- 每一屏都 sticky，用户会失去进度感。
- 只有视差，没有叙事顺序，会像前端特效展示。
- 颜色突变但内容语义不变，会显得廉价。
- 所有图层都动，主焦点会被稀释。
- 正文阅读区仍然做强视差，会影响理解和可访问性。
- 移动端照搬桌面长 sticky，容易卡顿、晕动或滚不到重点。

## 设计检查

做滚动落差前，先问 6 个问题：

- 第一滚，用户看到的是离场、入场，还是普通上移？
- sticky 停住时，用户获得了什么新信息？
- 每个落差点有没有对应的叙事原因？
- 强切换处是不是同时换了颜色、材质和语义？
- 页面有没有稳定锚点帮助定位？
- 后半段是否回到可读、可点、可完成任务？

## 记忆句

好的滚动落差，不是让页面动得更多，而是让滚动距离被叙事重新分配。
