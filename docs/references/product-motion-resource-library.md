# 产品动效资源库筛选卡

## 场景

- 做产品动效、UI Motion、微交互、App 页面切换、网页滚动动画时，需要长期稳定的灵感来源。
- 容易只看最终截图，而忽略动画的节奏、触发条件、状态反馈和过渡逻辑。
- 给“小晴”这类 Flutter + AI Agent + 陪伴机器人做体验时，动效不只是装饰，而是角色人格、反馈可信度和情绪氛围的一部分。

## 关键判断

产品动效参考不要只按“好看”收藏，要按用途分层：

- **真实 App 交互**：看页面切换、Tab、BottomSheet、输入反馈、聊天流程。
- **UI 微交互**：看按钮、Loading、Hover、Scroll、Onboarding 的节奏和状态。
- **高端官网动画**：看 Hero、Scroll Storytelling、WebGL、品牌氛围。
- **品牌 Motion**：看 Logo Motion、产品发布动画、宣传片节奏。
- **可落地素材与工具**：看 Lottie、Rive、Spline 这类能直接进入实现链路的资源。

最值得研究的问题不是“这个动画酷不酷”，而是：

> 这个动画为什么舒服？它在帮用户理解什么状态变化？

## 资源清单

### UI 动效灵感

- [Kisto](https://kisto.app/)
  - 推荐指数：★★★★★
  - 适合看 App 动效、Loading、页面切换、微交互、Button、Onboarding、Hover、Scroll Animation。
  - 案例以视频为主，适合逐帧研究“触发 - 过渡 - 落点”。
  - 重点页面：[UI Animation Inspiration](https://kisto.app/inspiration/ui-animation)

- [Flow Inspirations](https://createwithflow.com/inspirations/)
  - 推荐指数：★★★★★
  - 收录 Twitter、Alto's Odyssey、Castro、Two Dots 等经典案例。
  - 适合看行业经典 App 动效，也适合 Flutter 动效学习者反复拆解。

- [Ripplix - Website UI Animation](https://www.ripplix.com/platform/website-ui-animation/)
  - 推荐指数：★★★★☆
  - 专注 Website Animation、Scroll、Hover、Hero Animation、Loader、Navigation。
  - 适合 Framer、React、GSAP、Motion 方向的开发参考。

### 高端官网与品牌动画

- [Awwwards](https://www.awwwards.com/)
  - 推荐指数：★★★★★
  - 适合看 Hero Animation、Scroll Storytelling、WebGL、Three.js、GSAP。
  - 重点不是照搬视觉，而是学习“首屏叙事 + 滚动推进 + 技术质感”的组合方式。

- [Godly Website](https://godly.website/)
  - 收集高质量网站。
  - 虽然不是专门动效站，但很多交互、转场和页面节奏值得拆。

- [Motion Folios](https://motionfolios.com/)
  - 推荐指数：★★★★★
  - 收录全球 Motion Designer 作品集。
  - 适合小晴宣传片、产品发布动画、Logo Motion、品牌氛围参考。

- [Behance Motion](https://www.behance.net/galleries/motion)
  - Adobe 官方 Motion 频道。
  - 可搜索 `UI Motion`、`Product Animation`、`Motion Graphics`。

### 真实 App 拆解

- [Mobbin](https://mobbin.com/)
  - 推荐指数：★★★★★
  - 主体是 UI 案例库，新版也有不少操作视频。
  - 适合研究页面切换、Tab 动画、BottomSheet、iOS 交互、聊天产品和 AI 产品流程。

- [Page Flows](https://pageflows.com/)
  - 录制真实 App 的完整交互流程。
  - 适合看 Airbnb、Spotify、Notion、ChatGPT 等产品从入口到结果的完整路径。

### 可落地动效工具与素材

- [LottieFiles](https://lottiefiles.com/)
  - 推荐指数：★★★★★
  - 适合 Loading、Empty、Success、Error、Celebration 等轻量动效素材。
  - Flutter 项目很常用，适合快速落地反馈状态。

- [Rive](https://rive.app/)
  - 推荐指数：★★★★★
  - 适合做 AI 小助手、Live Avatar、按钮反馈、呼吸动画、表情切换。
  - 对“小晴”尤其重要：角色待机、眨眼、说话、情绪状态都可以系统化。

- [Spline](https://spline.design/)
  - 适合 3D、Web、动画和官网 Hero。
  - 可以做首页 3D 漂浮元素、视觉亮点和轻量交互场景。

## 每日浏览顺序

如果每天只看几个网站，按这个顺序：

1. [Kisto](https://kisto.app/)：看 UI Motion 和微交互。
2. [Mobbin](https://mobbin.com/)：看真实 App 流程。
3. [Awwwards](https://www.awwwards.com/)：看网页叙事和高端动效。
4. [Flow Inspirations](https://createwithflow.com/inspirations/)：看经典 App 动效。
5. [Behance Motion](https://www.behance.net/galleries/motion)：看大神作品和品牌 Motion。
6. [Motion Folios](https://motionfolios.com/)：看作品集表达和产品发布节奏。
7. [Rive](https://rive.app/)：看可交互角色与状态机动效。
8. [LottieFiles](https://lottiefiles.com/)：找可落地反馈素材。

## 小晴重点方向

结合小晴项目的 Flutter、AI Agent、陪伴机器人定位，优先看这几类：

- **Rive**：角色待机、眨眼、呼吸、说话、情绪切换。
- **Kisto**：输入框、按钮、卡片、聊天气泡等微交互。
- **Mobbin**：聊天产品、AI 产品、移动端完整流程。
- **Awwwards**：启动页、故事化介绍、品牌氛围。
- **Spline**：首页 3D 漂浮元素和视觉亮点。
- **LottieFiles**：Loading、Empty、Success、Error、Celebration 等系统反馈。

## 稳定解法

每次看动效参考时，用同一套拆解表，不要只收藏链接：

```md
## 动效案例拆解

- 来源：
- 场景：按钮 / Loading / 页面切换 / 聊天气泡 / 角色状态 / 官网 Hero
- 触发：点击 / 输入 / 滚动 / 等待 / 状态变化
- 动作：位移 / 缩放 / 透明度 / 模糊 / 弹性 / 路径 / 3D
- 节奏：快进快出 / 慢进快出 / 弹性 / 分段延迟
- 帮用户理解了什么：
- 可复用到小晴哪里：
- 实现方向：Flutter Animation / Rive / Lottie / GSAP / Three.js / Spline
```

看完一个案例，至少落一句判断：

```md
这个动效舒服，是因为它把状态变化拆成了「先响应用户、再组织信息、最后稳定落位」三段。
```

## 练习方式

- 每天选 1 个 Kisto 或 Mobbin 视频，拆 3 个关键帧：开始、中间、结束。
- 每周选 1 个 Awwwards 或 Godly Website 案例，只拆首屏和第一次滚动，不贪多。
- 每周选 1 个 Rive 或 Lottie 案例，判断它适合做“小晴”的哪一种状态反馈。
- 每个案例只写 5 分钟，目标是训练判断，不是写长评。

## 记忆句

产品动效先服务状态理解，再表达品牌情绪，最后才追求视觉惊艳。
