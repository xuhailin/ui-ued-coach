# SIRUP Playlist Site 视觉与动效拆解卡

## 场景

- 参考对象：[SIRUP - Apple Music : New Year Starters 2021 - Playlist Site](https://tote.design/sirup/)
- 这是一个音乐歌单专题站，不是常规产品落地页。
- 页面目标不是快速解释功能，而是把“听歌、艺术家、曲目、视觉海报、音乐氛围”揉成一个可滚动的沉浸式体验。
- 容易误读成“颜色很炸、元素很多”，但真正值得学的是它如何用严格网格控制高密度视觉。

## 关键判断

它有个性，不是因为堆了很多特效，而是因为三套语言同时成立：

- **唱片海报语言**：超大衬线字、手写签名、照片、歌词、编号、黑色粗线，像一张被横向展开的音乐杂志。
- **网页交互语言**：横向滚动、hover 播放 YouTube、移动端触摸/桌面滚轮响应、进入前 loading、音量控制。
- **WebGL 质感语言**：3D 斗鱼、图片 shader 扭曲、RGB/曲面偏移、滚动触发线条重绘，让静态海报有“活的介质”。

记住这个判断：它不是把网页做得像海报，而是把海报做成了一台能播放音乐的横向机器。

## 视觉系统

### 1. 构图：横向长卷，而不是普通页面

- 主体容器宽度约等于 `956vh`，每个 panel 按 `vh` 定宽。
- 桌面端页面纵向滚动，但内容被转换成横向位移。
- 这让用户感觉不是“往下读页面”，而是在横向扫过一排唱片封面、歌词页和杂志跨页。

可复用点：

```css
.page-main {
  display: flex;
  width: 956vh;
  height: 100vh;
}
```

横向叙事适合音乐、展览、作品集、时间线和活动专题。不适合高频表单、复杂导航和需要快速查找的信息站。

### 2. 色彩：酸性渐变打底，黑色网格压住

页面背景是一条从黄、红、紫、蓝到绿的横向渐变：

```css
background: linear-gradient(
  to right,
  #FFE401 0%,
  #FD1701 29%,
  #CD00A0 55%,
  #000ED3 72%,
  #00CC01 100%
);
```

它敢用高饱和色，但没有失控，原因是：

- 黑色线框把每个 panel 锁进结构。
- 大面积文字和图像基本使用黑色或强反差图片。
- 色彩主要负责情绪推进，不负责解释信息。

学习点：强色页面需要一个“冷静的骨架”。这里的骨架就是黑色 1px 分割线、巨大文字边界和固定 panel 宽度。

### 3. 字体与图像：把文字当成画面，不只当内容

页面大量标题、歌名、歌词、编号都以 PNG/SVG 图片形式出现。好处是可以彻底控制字形、裁切、竖排、变形、比例和图像混排。

典型手法：

- 超大衬线字被裁掉，只保留局部，形成背景建筑。
- 歌词小字密排在角落，作为质感层而不是正文阅读主体。
- 竖排文字、横排文字、手写签名叠在同一屏，制造音乐杂志感。
- 鱼、唱片、人物照片、脚部图片、线框几何同时出现，形成材质冲突。

为什么不乱：

- 每屏仍然围绕一个主角：鱼、艺术家照片、巨型标题或曲目图像。
- 细字只做肌理，不抢主焦点。
- 黑色网格线持续提供位置感。

### 4. 材质：真实鱼 + 扁平排版 + 线框几何

斗鱼是最强记忆点。它不是普通装饰图，因为它具备三种作用：

- **色彩锚点**：鱼身的蓝、青、橙和背景酸性色互相呼应。
- **前景深度**：鱼压在文字和照片上方，建立强遮挡关系。
- **生命感**：GLTF 动画让海报不只是平面拼贴。

线框圆柱、三角锥、唱片圆形和竖线让页面有一层“图形工程感”。这和手写签名、歌词、照片的有机质感形成反差。

## 动效与特效

### 1. Loading：先建立仪式感

进入前是黑底、黄色 “ENJOY TO LISTEN” 点击入口、旋转插画。它先把用户从普通网页浏览状态切到“准备听歌”的状态。

这个 loading 不是为了炫耀加载过程，而是给音频/视频资源加载争取时间，同时把第一次点击变成播放授权。

### 2. 滚动转横移：纵向输入，横向输出

桌面端监听 `scrollTop`，再用缓动把主内容平移：

```js
props.mainTop = (props.pageTop - props.mainTop) * props.ratio + props.mainTop;
main.style.transform = `translate3d(${-props.mainTop}px, 0, 0)`;
```

这里的关键是 `ratio: 0.125`。它让横移有滞后感，页面不会像普通滚动那样机械，而是像唱片带或展览墙在慢慢被拖动。

### 3. 入场：IntersectionObserver 控制切片出现

每个图像切片有 `data-transition="up/down/left/right"`，进入视口后加 `js-lozad`，触发位移 + 透明度过渡。

```css
[data-transition="up"] {
  opacity: 0;
  transform: translate(0, 12.5vh);
}

[data-transition="up"].js-lozad {
  opacity: 1;
  transform: translate(0, 0);
  transition: opacity 1s linear, transform 1s cubic-bezier(0.215, 0.61, 0.355, 1);
}
```

这让高密度拼贴不是一次性砸出来，而是随着滚动一层层落位。

### 4. Shader：让静态图片像介质一样变形

页面把部分图片替换成 Three.js canvas，再用 shader 做滚动响应：

- `Wobbling`：用 sin/cos 让标题或图像产生水波扭动。
- `Curve`：滚轮触发横向曲面偏移，让图片像被唱片机/胶片拉扯。
- `RgbShift`：通道偏移，制造电子视觉和音乐现场感。

关键不是“用了 WebGL”，而是特效都围绕音乐介质：

- 波动像声音。
- 通道偏移像模拟视频。
- 曲面扭曲像纸张、唱片、屏幕被拖拽。

### 5. 音乐同步：hover panel 播放对应 YouTube

桌面端预加载 16 个 YouTube iframe。鼠标进入对应 panel 时，暂停其他 player，播放当前曲目。

这让页面从视觉专题变成“可听的歌单界面”。它的交互主轴不是按钮导航，而是探索式 hover。

### 6. 光标：鼠标变成页面的一部分

桌面端自定义一个 `40vh` 的巨大 cursor，不同 panel 切换不同图像，还会翻转或隐藏。

这不是小装饰，而是把“鼠标位置”变成视觉层。用户的动作会直接改变页面质感。

## 技术结构

可以把它拆成 5 层：

1. **HTML 切片层**：每个 panel 是一组绝对定位图片、线条、链接和歌词切片。
2. **CSS 编排层**：用 `vh` 作为统一尺度，保证横向海报在不同桌面高度下保持比例。
3. **滚动控制层**：纵向页面高度映射到横向 `translate3d`。
4. **媒体层**：YouTube iframe 预加载、hover 播放、音量按钮控制。
5. **WebGL 层**：Three.js shader 替换图片、GLTF 斗鱼动画、持续 RAF 渲染。

主要技术关键词：

- `Three.js`
- `GLTFLoader`
- `ShaderMaterial`
- `TextureLoader`
- `IntersectionObserver`
- `requestAnimationFrame`
- `TweenMax / TimelineMax`
- `YouTube Iframe API`
- `createjs.LoadQueue`

## 为什么高级

- **强刺激但有秩序**：颜色、鱼、巨字都很野，但黑色网格和固定 panel 尺寸让页面不散。
- **技术服务主题**：WebGL 不是孤立炫技，水波、鱼、音乐、视频通道感都指向“听歌”和“流动”。
- **信息不按常规层级走**：它牺牲了传统可读性，换来强烈的艺术编辑感，适合歌单专题。
- **材质混合非常明确**：照片是真实的，字是平面的，线框是工程的，鱼是生命体，几种材质互相撞击。
- **交互像 DJ 操作台**：滚动换曲、hover 播放、音量开关、ticker 链接、变形光标，让用户像在扫一张会响的海报。

## 可复用方法

如果要借鉴到自己的页面，不要照搬鱼或酸性渐变，而是复用这套结构：

1. 先定一个强媒介隐喻：唱片、胶片、展览墙、航海图、控制台、书页。
2. 用一条严格骨架管住页面：网格、分栏、横向长卷、固定比例 panel。
3. 给每屏一个主焦点：大图、大字、视频、角色或物件，只留一个主角。
4. 把装饰拆成层：背景色、网格线、巨字、图片、细字、前景物、动效。
5. 动效只响应主题：音乐就波动/通道偏移，地图就轨迹/缩放，展览就灯光/视差。
6. 让交互改变内容状态，而不是只改变按钮颜色。

## 反模式

- 只复制高饱和渐变，会变成廉价酸性背景。
- 只堆大字、照片、贴纸，没有网格骨架，会变成乱贴素材。
- WebGL 特效和主题无关，会显得像前端 demo。
- 所有元素都动，会削弱主焦点。
- 在严肃产品页照搬这种可读性，会牺牲转化和任务效率。

## 练习

用 2 小时做一个低保真复刻练习：

```md
主题：选 3 首歌或 3 个作品
画布：横向 3 个 panel，每个 100vh 宽
骨架：黑色 1px 分割线 + 酸性渐变背景
素材：每屏一个主图 + 一个巨型裁切字 + 一段小字肌理
动效：滚动横移 + 一处图片轻微扭曲 + 一个 ticker 链接
限制：不要超过 3 种主色，不要让每个元素都动
```

完成后只问 3 个问题：

- 主焦点是不是一眼能找到？
- 高饱和色有没有被黑色结构压住？
- 动效是否在解释“音乐/媒介/内容”，还是只是在炫？

## 记忆句

强个性页面不是把元素做疯，而是先立一套严密骨架，再允许视觉在骨架里失控。
