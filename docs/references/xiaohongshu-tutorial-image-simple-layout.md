# 小红书商务合作教程图：极简截图版式

## 场景

- 用于小红书商务合作中的产品功能介绍、操作教程和使用提示图。
- 素材通常是已经准备好的产品截图，只需要整理成可直接发布的竖版图片。
- 用户偏好“像参考教程图一样简单”，不需要重新设计一套宣传海报。
- 最常见的误区是擅自添加品牌角标、页码、卡片、渐变、装饰线、复杂说明和营销口号，结果比原始截图更乱。

## 关键判断

这类图的目标不是“做得更像广告”，而是让用户一眼看懂操作顺序。

默认视觉优先级只有三层：

1. 一句步骤或提示标题。
2. 对应的产品截图。
3. 上下段之间的留白。

如果删掉角标、页码、Logo 和装饰后仍能讲清楚，就全部删掉。

## 固定版式

- 画布：`1080 × 1440`，3:4 竖图。
- 背景：纯白色。
- 字体：`Songti SC`、`STSong` 或其他中文宋体。
- 文字颜色：暖棕色，参考 `#694b38`。
- 内容边距：左右约 `76px`，顶部约 `78px`。
- 标题字号：通常 `38–42px`；如果用户要求单行，缩小到约 `30–36px`，不要强行换行。
- 截图：保持原始比例，不拉伸、不裁掉关键操作、不加阴影和圆角。
- 一张图通常分为上下两段，每段只有“标题 + 截图”。

基础结构：

```html
<main class="poster">
  <section class="step">
    <h1>第一步：打开产品页面，进入目标功能</h1>
    <img src="step-1.png" alt="步骤一截图" />
  </section>

  <section class="step">
    <h1>第二步：输入提示词，点击生成</h1>
    <img src="step-2.png" alt="步骤二截图" />
  </section>
</main>
```

```css
.poster {
  width: 1080px;
  height: 1440px;
  padding: 78px 76px 64px;
  overflow: hidden;
  background: #fff;
  color: #694b38;
  font-family: "Songti SC", "STSong", serif;
}

h1 {
  margin: 0 0 44px;
  font-size: 42px;
  font-weight: 500;
  line-height: 1.45;
}

img {
  display: block;
  max-width: 100%;
  height: auto;
  object-fit: contain;
}
```

## 截图排列规则

### 两张步骤截图

- 按操作顺序上下排列。
- 标题紧跟对应截图，不要另外增加说明段落。
- 横向截图可以铺满内容宽度；接近方形或竖向截图可使用原始宽度并居中。

### 一张横图加一张结果图

- 用户说“某张不缩小放上面”时，横图按内容区最大宽度完整展示。
- 用户说“另一张居中”时，恢复原始尺寸或合理最大尺寸，并水平居中。
- 不根据文件编号猜顺序；先查看素材，再按用户指定的上下关系排版。

### 一张合并长图

- 如果新资料本身已经包含多组记录，不再拆图。
- 保留一条提示标题，长图按原比例居中放置。
- 高度接近画布底部时，优先缩小整张图，不裁切内容。

## 文案规则

- 步骤文案直接写动作，例如：`第二步：输入提示词，点击生成，也可以用提示增强`。
- 提示文案只保留一句，例如：`小提示：可以上传参考图片，也可以将生成的图片作为参考哦。`
- 用户要求单行时，必须保持单行；通过减小字号解决，不添加手动换行。
- 不自行添加方括号、引号、标签、序号角标或宣传性副标题。
- 用户原句有明显输入错误时，可以修正错别字，但不要改变意思。

## 禁止项

- 不加左上角品牌标识。
- 不加右上角页码或“第几张”角标。
- 不加紫色标签、胶囊、徽章或步骤卡片。
- 不加渐变背景、阴影、描边和装饰图形。
- 不把截图做成悬浮卡片。
- 不为了填满画布而放大低分辨率截图。
- 不同时出现多个解释标题，避免信息重复。

## 稳定制作流程

1. 先查看所有素材并记录尺寸、横竖比例和关键操作区域。
2. 用 HTML/CSS 搭建 `1080 × 1440` 固定画布。
3. 只写用户确认过的标题，把截图按原比例放入。
4. 浏览器导出 PNG。
5. 检查标题是否单行、截图顺序是否正确、关键按钮是否可辨认。
6. 修改版本另存新文件；只有用户明确要求更新原图时才覆盖。

## 交付检查

- [ ] 是否为纯白背景？
- [ ] 是否只有标题和截图？
- [ ] 是否没有角标、页码、Logo 和装饰？
- [ ] 标题是否按用户要求保持单行？
- [ ] 图片顺序是否与用户指定一致？
- [ ] 截图是否保持原比例？
- [ ] 关键操作区域是否清楚可见？
- [ ] 输出是否为 `1080 × 1440` PNG？
