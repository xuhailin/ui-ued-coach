# 木木一家手帐 IP 设计语言卡

## 场景

- 固定一套“小禾 / 木木妈妈 / 木木爸爸 / 木木”的家庭系列 IP 设定，用于日更手帐、小红书图文、贴纸、绘本式分镜。
- 角色核心是“日本生活绘本里的妈妈”：会带娃、写代码、做手帐、处理工具和平台问题，也会用咖啡、冰淇淋、水果奖励自己。
- 容易误读成“画一个妈妈和孩子”或“堆一些生活素材”，但真正要保留的是角色识别、纸感、分镜节奏和温柔的生活叙事。

## 角色设定

公开称呼：

- **木木妈妈**

角色昵称：

- **小禾**

系列标题：

- **木木妈妈的一天手帐**

木木妈妈固定识别锚点：

- 高马尾，绝不散发。
- 身材纤细，气质利落但柔软。
- 粉色、白色、绿色系衣服；夏天以短袖为主。
- 运动鞋。
- 有时戴 Apple Watch。
- 工作时永远抱着或使用 MacBook。
- 喜欢咖啡、冰淇淋、水果。
- 表情自然，不画成夸张动漫脸。

木木爸爸固定识别锚点：

- 戴黑框眼镜。
- 正常体型，不画成胖，也不要过瘦。
- 头发偏分。
- 也是程序员。
- 气质偏严肃、克制、可靠，有一点霸总式压迫感，但穿着仍然是生活里的正常短袖，不穿西装。

记忆目标：

> 用户刷到时能立刻觉得：啊，木木妈妈又更新今天的手帐了。

## 关键判断

这个 IP 不是普通妈妈插画，而是“家庭生活方式型手帐 IP”。

它成立的关键不在具体事件，而在三件事同时稳定：

- **角色稳定**：木木妈妈的高马尾、纤细身形、自然表情、浅色衣着反复出现；木木爸爸的黑框眼镜、正常体型、偏分头发、程序员身份和严肃压迫感保持稳定。
- **媒介稳定**：奶油纸张质感、彩铅线条、水彩淡涂、手写字体。
- **叙事稳定**：一天被拆成小漫画分镜，忙乱和烦恼最终被温柔收束。

## 视觉语言

### 画风

- 奶油纸张质感。
- 彩铅 + 水彩。
- 浅绿色、奶茶色、米白色为主。
- 小漫画分镜。
- 手写字体。
- 大量留白。
- 安静、治愈、轻微好笑。

### 色彩

主色：

- 米白、奶茶、浅灰、浅绿色。

辅助色：

- 柔和棕色、低饱和蓝灰、浅粉。

点缀色：

- 红心、绿色勾、黄色警告、小太阳、水果红。

稳定原则：

- 所有颜色都要像被纸张吸收过，避免糖果粉、高饱和韩系色、强荧光色。
- 粉色和绿色只做气质提示，不要大面积铺满。

### 线稿

- 线条用深棕灰，不用纯黑。
- 人物轮廓比内部细节略重。
- 边框线要松，不要像 UI 组件一样硬。
- 保留手绘抖动感，但不能草稿脏乱。

### 版式

- 使用手帐页式小漫画分镜。
- 一格只讲一个小事件。
- 每格都要有呼吸区，避免信息塞满。
- 上方可放日期、标题、心情天气；下方按编号记录一天。
- 结尾最好有“夜晚收尾 / 今日总结”，让一天有完成感。

## 编辑规则

### 1. 主角必须反复出现，但姿态要变化

观察：木木妈妈在幼儿园、电脑前、工具切换、平台警告、吃水果、夜晚收尾中反复出现。

意图：让用户建立角色识别，同时避免头像式重复。

迁移：未来任何主题都应保持“同一角色、多场景姿态”，不要只换背景。

### 2. 高马尾是第一识别符号

观察：主角每次出现都保持高马尾或清晰束发轮廓。

意图：高马尾让角色显得利落、年轻、忙碌，也形成远距离识别。

迁移：这是 IP 资产，必须保留；不要散发、低马尾、短发或随意换发型。

### 3. 压力事件要温柔化处理

观察：孩子哭闹、工具不可用、平台警告、忙碌工作都被浅色、手写字、小装饰和自然表情软化。

意图：让用户感到“我也这样，但没关系”，而不是被焦虑压住。

迁移：系列里可以有崩溃和麻烦，但不能画成尖锐、阴暗、强冲突。

### 4. 生活物件只做身份补充

观察：MacBook、咖啡、饭盒、冰淇淋、水果都存在，但尺寸和细节被控制。

意图：物件用来证明她的生活方式，不把画面变成美食图、数码图或育儿用品图。

迁移：未来新增物件时必须服务角色和故事，不要变成素材库拼贴。

### 5. 手写文字承担叙事，插画承担情绪

观察：文字解释每天发生什么，插画表现状态和温度。

意图：降低插画必须讲清全部剧情的负担，让画面更轻。

迁移：继续保留手写旁白；文案要像妈妈自己写的，不要像广告口号。

## AI 生成风险

### 1. AI 会把妈妈画成普通二次元少女

观察：目标角色是自然表情、生活绘本感，不是动漫女主。

意图：她要让用户相信“这是一个真实生活中的妈妈”，而不是虚拟偶像。

迁移：提示词必须强调 natural expression、Japanese lifestyle picture book mother、no exaggerated anime face。

### 2. AI 会忘记高马尾

观察：高马尾是系列最强识别符号。

意图：发型负责用户一眼认出 IP。

迁移：把 high ponytail, never loose hair 放进角色设定前几句，不要只写一次。

### 2.1 AI 会把木木爸爸画得太胖、太软萌或太西装霸总

观察：木木爸爸的识别点是黑框眼镜、正常体型、偏分头发、程序员身份，以及偏严肃克制、略有压迫感的气质。

意图：爸爸要像家庭生活里的真实程序员爸爸，有严肃感、可靠感和一点霸总式气场；但穿着仍然日常，不是胖爸爸、软萌爸爸，也不是西装精英男。

迁移：提示词必须明确 black rectangular glasses、normal body shape、not chubby、side-parted hair、serious and restrained programmer father、subtle commanding aura、normal short-sleeve clothes；负向提示里排除 chubby father、soft-cute father、business suit、cold villain father。

### 3. AI 会让颜色漂移

观察：原风格依赖米白、奶茶、浅绿、低饱和粉。

意图：低饱和色让画面有日本文具感和纸张温度。

迁移：生成时限制 muted cream paper、pale green、milk tea beige、off white、soft pencil watercolor。

### 4. AI 会把生活物件堆成素材库

观察：物件需要围绕一天的故事线出现。

意图：每个物件都是叙事证据，不是装饰库存。

迁移：生成前先写当天故事线，再选择物件；不要无目的添加咖啡、花、星星和食物。

### 5. AI 会让版面太满

观察：原画面依赖留白、分镜间距和低密度呼吸感。

意图：留白把琐碎日常变成可阅读的手帐。

迁移：提示词加入 lots of blank space、sparse layout、one small event per panel。

## 不应迁移

这些属于单日主题内容，不是风格本身：

- 某个具体平台警告。
- 某个具体工具名。
- 某一天吃的李子、冰淇淋或饭盒。
- 某一天的天气图标。
- 某一次幼儿园哭闹。

真正要迁移的是：

- 固定角色识别。
- 家庭成员各自有稳定识别锚点，不互相抢戏。
- 分镜日记结构。
- 纸张和彩铅水彩质感。
- 低饱和浅色系。
- 生活烦恼被温柔收束的叙事方式。

## 记忆句

木木一家不是“妈妈、爸爸、孩子的随机组合”，而是一套稳定的日更手帐语言：高马尾妈妈、黑框眼镜严肃程序员爸爸和木木，在柔软纸感里把忙乱的一天收成一页安静的小漫画。
