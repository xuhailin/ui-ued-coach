# 智能体发展史时间轴卡

## 来源

- Datawhale Hello-Agents：第一部分第二章《智能体发展史》
- Datawhale Hello-Agents：第四章《智能体经典范式构建》

## 关键判断

智能体的发展不是简单从“弱 AI”到“强 AI”，而是围绕一个反复出现的问题演进：上一代系统解决了某个能力短板，同时暴露新的边界。现代 LLM Agent 可以理解为历史上几条路线的融合：符号推理、模块协作、数据学习、强化反馈、预训练世界知识、工具调用、记忆与反思。

## 时间轴

| 阶段 | 代表节点 | 解决了什么 | 暴露了什么 |
| --- | --- | --- | --- |
| 1950s-1970s 符号主义 | 物理符号系统假说、逻辑 AI | 把智能工程化为符号表示、规则推理和搜索 | 依赖人手编码，难覆盖开放世界 |
| 1966-1970s 规则系统 | ELIZA、MYCIN、SHRDLU | 证明规则系统能在特定场景里表现出智能行为 | 缺乏真正语义理解，离开封闭领域就脆弱 |
| 1980s 局限暴露 | 知识获取瓶颈、常识问题、框架问题 | 让研究者看清“只靠规则”无法规模化 | 需要新的知识获取与适应机制 |
| 1986 分布式智能思想 | 明斯基《心智社会》 | 提出智能可由多个简单模块协作涌现 | 协调、分工和冲突处理变成新问题 |
| 1990s-2010s 学习范式 | 神经网络、深度学习、强化学习、AlphaGo | 让能力从数据和环境反馈中学习出来 | 需要大量数据，通用知识和可控推理仍不足 |
| 2018-2022 大模型预训练 | Transformer、GPT 系列、CoT | 模型通过预训练获得世界知识、上下文学习和通用推理能力 | 仍有幻觉、时效性、行动能力和长期记忆问题 |
| 2022-Now LLM Agent | ReAct、Plan-and-Solve、Reflection、Tool Use、Memory | LLM 作为认知中枢，连接工具、规划、记忆和反思，形成行动闭环 | 工具选择、上下文管理、评估、安全边界成为工程核心 |

## 一句话记忆

从写死规则，到让模型学世界，再到让模型接上工具行动。现代 Agent 不是单个 LLM，而是围绕 LLM 组织起来的“感知、思考、行动、观察、记忆更新”循环。

## 和第 4 章的衔接

- ReAct：边想边做，用 `Thought -> Action -> Observation` 把推理和工具反馈接成动态循环。
- Plan-and-Solve：先生成计划，再逐步执行，适合路径比较明确的多步任务。
- Reflection：执行后自我评审和优化，适合对质量和可靠性要求高的任务。
